## Release Policy

Version numbers follow Semantic Versioning:

* **MAJOR** — Breaking API changes
* **MINOR** — New features with backward compatibility
* **PATCH** — Bug fixes and maintenance

Example:

```text
1.0.0
│ │ └── Patch
│ └──── Minor
└────── Major
```
